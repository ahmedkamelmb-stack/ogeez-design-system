# Spine

The brand's DNA. Read in order. Every other doc in this repo cites these.

1. **`manifesto.md`** — the spine. Bilingual, locked v5, 2026-05-10. Read in full, once.
2. **`positioning.md`** — *Attention, not volume.* The four-word client-facing line.
3. **`voice.md`** — operational rules (~370 words). Cites the manifesto by paragraph.
4. **`register-matrix.md`** — brief-archetype → craft-move lookup table.

## The single most important sentence

> *في مستوى. / عند المستوى، أو مرفوض.*
>
> *There is a bar. At the bar, or refused.*

Every artifact, line of copy, and design decision is measured against this.
