## How these are used

These are **brand assets**, not deliverables. Use them:

1. As the opener of a pitch deck (HeyGen video as slide 1, before the static deck).
2. As the closer of a recruiting page (the bumper as a quiet ambient loop behind the *Apply* CTA).
3. As reference for any future bespoke shoot — the register here is the register the brand wants on camera.
