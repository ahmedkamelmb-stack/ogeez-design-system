# Grid and Layout

The spatial system. Read in this order:

1. **`visual-system.md`** — grid, hierarchy, whitespace.
2. **`density-rules.md`** — anti-crowd doctrine, air-first.
3. **`do-and-dont.md`** — paired visual examples, six DO / six DON'T.

## The single most important rule

**Look less designed, not more.** Margins generous, body restrained, one image, one headline, one signal. If a slide needs more than that, it needs to become two slides.

## Where this docks with the rest of the system

- **Color complement:** `01-tokens/palette-rules.md` (one signal per artifact + substrate-carries-the-rest).
- **Typography complement:** `02-typography/bilingual-typography.md` (equal-weight, idea-native).
- **Motion complement:** `05-motion/motion-system.md` (held, observational).

The four together describe the OGeez look. Any one alone misses.
