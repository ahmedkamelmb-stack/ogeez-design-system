# Icon System

## Status

V2 specifies the icon system; the full SVG library is a V2.1 build task.

## Principles

- Stroke-based, not filled.
- Rounded joins kept minimal.
- Optical weight matches Modern Era Medium.
- Icons should feel like production notation, not app-store generic.
- Use icons for tools, states, roles, locations, and deliverables.

## Domains

1. Production: camera, slate, lens, light, boom, edit, color, sound.
2. Locations: Cairo, Riyadh, studio, exterior, interior, set, road.
3. Roles: director, producer, writer, cast, client, crew.
4. Status: approved, draft, locked, risk, urgent, waiting.
5. Files: treatment, deck, budget, call sheet, release, script.
6. Navigation: arrow, close, plus, filter, search, download, upload.
7. Social: Instagram, TikTok, YouTube, LinkedIn, web.

## Rules

- Use symbols where symbols are familiar.
- Use text labels only when the icon is not self-evident.
- Never make icons decorative filler.
- Use tooltips in interactive surfaces.
