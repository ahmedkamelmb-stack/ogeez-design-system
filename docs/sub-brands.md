# Sub-Brands — Internal Only

## V3 status (2026-05-10)

Per the v5 brand reset architectural decision **(b — singular brand, departments invisible to clients)**, all sub-labels are **dev-internal only**. Clients see one face: OGeez. The sub-brand token slots in `tokens.css` exist for debugging, internal documentation, and developer tooling — never for client-facing surfaces.

## Why dev-internal?

Internal department labels (the AI bench, the Sold Out writing room, the shorts arm, Cairolog, the authored films) carry their own working modes inside the studio. They have meaning for billing, for crew lists, for internal briefing. None of that is visible from the client side. From the client side, OGeez ships the work.

Per manifesto ¶8:

> الشكل واحد. أربع إيدين وراه. Some hands are better in the room. Some hands are better with the cuts. Some hands run the calendar in Riyadh. Some hands run the slate in Cairo. The face the client meets is one. The work the client receives carries every hand.

## What about *OGeez Presents*?

The *OGeez Presents* surface (`docs/film-context.md`) is **not** a sub-brand. It's a project-level convention for authored films — *OGeez Presents Mabeen*, *OGeez Presents Halayeb* — where the studio's name and wordmark stay constant and the per-film artwork is bespoke. A24-precedent.

This is different from a sub-brand because:
- It's a presentation surface, not a separate identity.
- The studio's name and wordmark stay.
- The per-film visual world is the *film's*, not a sub-brand's.

## Rule

Never invent new sub-brands or surface them to clients. If a project requires a separate label visible to the public, that's a project-level decision (e.g., the *OGeez Presents* surface for authored films), not a sub-brand decision.
