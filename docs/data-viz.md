# Data Visualization

## Purpose

OGeeZ data-viz should feel like production intelligence, not SaaS dashboard decoration.

## Primitives

1. Bar.
2. Line.
3. Area.
4. Stacked bar.
5. Donut.
6. Timeline.
7. Pipeline.
8. Region map.

## Palette Rules

- Use one tone family plus one disruptor.
- Black carries the strongest data series.
- Do not use all house colors at once.
- Tune palette to context:
  - `house`: Green / Ultramarine / Epink + black.
  - `oncamera-corporate`: black + taupe + muted neutrals.
  - `oncamera-consumer`: client palette plus one high-chroma accent.
  - `film`: white/grey on black, one green accent only.

## Typography Rules

- Numbers use Modern Era Mono when comparing rows.
- Arabic labels use Arabic font and adequate line height.
- Captions explain the implication, not the obvious value.

## Layout Rules

- No chart should be louder than the idea slide.
- Charts in decks need a sentence above them saying what changed.
- Avoid 3D, bevels, gradients, and decorative shadows.
