# OGeez Register Matrix

Lifted clean from v4 voice guidelines (now archived). Brief-archetype → craft-move table is unchanged from v4 — the moves and registers themselves are the same. Use [[manifesto-2026-05-10]] and [[voice]] as the spine; this file is the lookup.

## The 11+1 craft moves

1. **Inversion** — flip the brief's framing; the inversion becomes the idea.
2. **Refusal framing** — define by what we don't do.
3. **Specific-over-impressive** — concrete nouns over abstract adjectives.
4. **Attention vs. volume** — frame loud, copy quiet; image carries what copy withholds.
5. **Probability-weighted counterpoints** — disagreements with ourselves come with `P ≈ 0.xx`.
6. **Dialect as craft** — language choice is a production decision; never a cosmetic.
7. **The second of silence** — held beat where competitors fill with music or punchline.
8. **Pull-back reveal** — start tight on a specific object, pull back; the reveal is the punchline.
9. **Scale-concrete comparison** — show 1 unit, show 20 units, show distance to the big number.
10. **POV-as-narrator** — silent object holds the camera; the silence is load-bearing.
11. **Match-cut past/present** — two shots, different eras, identical framing; the cut collapses time.
12. *(provisional)* **Pull-back to user** — rotate the pull-back reveal endpoint from product to person.

## The 3 tonal registers

- **A — Netflix-mockumentary.** Talking-head, deadpan aside-to-camera, chyron-as-irony. For briefs whose subject is people, not products.
- **B — Thought-leader speech.** Literary Arabic, TED-grammar pacing, collage stage visuals. Reserved for CEO, founder, state-actor briefs.
- **C — Vertical comedy / هلس.** Short-form, single-location, escalating absurdity. Egyptian sketch lineage.

## Two-track proposal structure

- **Repeat client** → idea-first deck. Slide 1 = the idea (one line + one image). Slide 2 = craft spine. Slide 3 = deliverables matrix. Credentials = 3-line signature at close.
- **First-time client** → 11-section template, lightly compressed. About / clients / partners / overview / objective / content plan / brand essence / tone / direction / pillars / photos. Rhythm is the move.

## How to use this matrix

Diagnose brief-type first. Pull the move combo from the table. Apply [[voice]] rules to the writing. Apply [[visual-brief-2026-05-10]] rules to the visual. The house picks the register from the brief, not the brief from the register.
